# Bookstack

## Setup

In Authentik, configure a OAuth2 provider. Use the redirect URL as
`https://bookstack.nathanv.app/oidc/callback`

## Bitwarden secrets

- `BOOKSTACK_APP_KEY`
- `BOOKSTACK_DB_DATABASE`
- `BOOKSTACK_DB_PASSWORD`
- `BOOKSTACK_DB_USERNAME`
- `BOOKSTACK_OIDC_CLIENT_ID`
- `BOOKSTACK_OIDC_CLIENT_SECRET`
- `BOOKSTACK_SMTP_HOST`
- `BOOKSTACK_SMTP_PASSWORD`
- `BOOKSTACK_SMTP_USERNAME`
