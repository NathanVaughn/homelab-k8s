# Paperless

## Bitwarden secrets

- `PAPERLESS_DB_DATABASE`
- `PAPERLESS_DB_PASSWORD`
- `PAPERLESS_DB_USERNAME`
- `PAPERLESS_OIDC_CLIENT_ID`
- `PAPERLESS_OIDC_CLIENT_SECRET`
- `PAPERLESS_SECRET_KEY`
- `PAPERLESS_SMTP_HOST`
- `PAPERLESS_SMTP_PASSWORD`
- `PAPERLESS_SMTP_USERNAME`

## Post Setup

After the first login, you'll need to manually make the new account a super user.
This is in the `auth_user` table.
